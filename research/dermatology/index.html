Dermatology Image–Text Curation and Evidence-Grounded Evaluation

Medical vision-language models can produce a fluent diagnosis without really looking at the image. This project builds traceable dermatology cases from the literature and designs an evaluation that tests whether an answer is supported by the evidence actually supplied.

Problem

A case taken from a published report is not immediately usable for evaluating a model:

01Mixed figures

One figure can contain several panels or modalities: clinical photograph, dermoscopy, histopathology.

02Leaky captions

The caption often names the diagnosis. The reference interpretation may also depend on examinations the model never sees.

03Answers without looking

A model can reproduce a plausible description from the history or from retrieved examples without inspecting the current image.

Data curation

The core data work collects dermatology cases from biomedical publications, links them through PubMed and PMCID identifiers, matches figures and panels to their captions, and keeps annotation and quality-control records. Each usable case keeps:

  • patient grouping, source article, figure or panel, and image type;
  • clinical history, reference interpretation, and where the evidence is located;
  • a permission record for reuse.

Model-visible vs. reference-only. A diagnostic caption can support scoring while staying hidden from inference. All images from one patient or article stay in one partition, so near-duplicates cannot leak between the evaluation sets.

Workflow

The workflow keeps current patient evidence separate from historical examples:

  1. The current case (image and clinical history) is the only evidence about this patient.
  2. A static memory holds verified records from a disjoint set of cases, retrieved by text similarity. Its score is a retrieval signal, not a probability that an answer is right.
  3. The model answers with its observations, evidence IDs, and what is missing.
  4. An optional evidence audit checks the answer against the image, history, and retrieved cases for unsupported observations and missing evidence.

Programmatic checks validate structure and provenance, but they do not establish clinical correctness. Memory stays verified and static, so model-generated interpretations are never automatically promoted to accepted facts.

Evaluation design

Does the answer depend on the image?

For each question, the history and question stay fixed while the visual evidence changes: the intact image, no image, the lesion occluded, and an equal-area background region occluded as a control. Answerability is reviewed separately for every probe. A partially masked image does not automatically require the model to abstain.

M2-R gives M3's extra call to a generic self-review, so any gain from the audit is not just a gain from spending more compute. Metrics: task accuracy, answer coverage, accuracy given an answer, unsupported answers on unanswerable probes, over-refusal on answerable probes, and independently reviewed unsupported visual claims. Missing outputs stay in the denominator, and the system's own verifier is never the only evaluator.

What is built

  • Offline prompt preparation, source-linked memory retrieval, and a connector for a configured image-capable model endpoint, with raw outputs and usage records preserved.
  • A scorer that checks partition overlap, imported memory IDs, duplicate predictions, response completeness, and reviewed answerability labels.
  • Software tests that confirm four properties: reference answers never enter prompts, memory/test source overlap is rejected, an always-refuse strategy cannot reach perfect accuracy, and missing outputs are counted.

These are software checks, not clinical results. No diagnostic accuracy, hallucination reduction, or memory benefit is claimed until the controlled study runs on real, reviewed cases.

Contribution

My contribution is the data work: case collection, image–caption alignment, annotation organization, and provenance tracking. The evaluation design and the retrieval and audit scaffold extend that work and were developed with AI assistance.
