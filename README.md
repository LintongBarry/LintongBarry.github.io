# lintongbarry.github.io

Personal academic homepage of Lintong Han. Static HTML/CSS/JS, served by GitHub Pages; no build step.

- `index.html` — main page
- `assets/` — styles, script (hero canvas, nav, reveal), images
- `projects/geo-loop/` — interactive GEO-Loop project page

Preview locally: `python3 -m http.server 8000` and open http://localhost:8000.
